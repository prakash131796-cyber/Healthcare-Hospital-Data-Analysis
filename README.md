# Healthcare & Hospital Data Analysis

## Project Overview
This project focuses on analyzing healthcare and hospital data to identify meaningful insights into patient demographics, hospital operations, department-wise performance, admission patterns, and billing trends. The analysis was performed using Python in Google Colab, with data manipulation, exploratory analysis, and visualization techniques.

## Development Environment
- Google Colab
- Python
- Jupyter Notebook (`.ipynb`)

## Technologies & Tools
- **Python:** Core programming and data analysis
- **Pandas:** Data manipulation and analysis
- **NumPy:** Numerical computations
- **Matplotlib:** Data visualization
- **Seaborn:** Statistical data visualization
- **Google Colab:** Cloud-based development environment

## Project Workflow

1. **Data Loading:** Imported and explored the healthcare dataset.
2. **Data Cleaning:** Identified and handled missing values and duplicate records.
3. **Data Preprocessing:** Prepared and structured the dataset for analysis.
4. **Exploratory Data Analysis (EDA):** Examined data distributions, patterns, and relationships.
5. **Patient Analysis:** Analyzed patient demographics and healthcare-related information.
6. **Department Analysis:** Explored department-wise patient distribution.
7. **Billing Analysis:** Examined hospital billing patterns and costs.
8. **Data Visualization:** Created charts and visual representations using Matplotlib and Seaborn.

## Key Analysis Areas
- Patient demographic analysis
- Department-wise patient distribution
- Hospital admission patterns
- Healthcare billing analysis
- Data distribution and statistical insights
- Visual exploration of healthcare data

## Project Files
- `health_care_project_1(1).ipynb` – Python healthcare data analysis notebook
- `healthcare_hospital_cleaned_DB.csv` – Cleaned healthcare dataset

## How to Run the Project

1. Download or clone this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the `.ipynb` notebook.
4. Upload the required healthcare CSV dataset.
5. Update the dataset file path if necessary.
6. Execute the notebook cells sequentially.

## Project Objective
To transform raw healthcare data into meaningful insights through data cleaning, exploratory analysis, and visualization, enabling a better understanding of patient information, hospital operations, and billing patterns.
